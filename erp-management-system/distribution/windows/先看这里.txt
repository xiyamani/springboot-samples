ERP 管理系统 - Windows 64 位免安装包

一、怎样使用
1. 将“ERP管理系统-免安装包.zip”整个压缩包发给对方。
2. 对方先解压到自己的文件夹，再双击“启动系统.cmd”。
3. 等待约 10 至 40 秒，浏览器会自动打开登录页。
4. 使用完毕双击“停止系统.cmd”。只关闭浏览器不会停止后台服务。

内含 Java 21 运行环境，无需安装 Java、Maven、MySQL 或 Navicat。
适用于 Windows 10 / Windows 11 的 64 位 x64 电脑；不适用于手机、Mac 或 Windows ARM。
不需要管理员身份运行；请解压到当前用户有写入权限的普通文件夹。
首次使用会创建独立的课程业务数据；对方的操作不会修改原作者电脑的数据。

二、登录账号

业务员建单并提交审批 -> 审批主管审批 -> 仓库员入库或出库。

三、访问与保存
默认地址：http://127.0.0.1:8087/
如果端口已被其他程序占用，会自动选择 8088 至 8107 中的空闲端口，并打开实际地址。
重新双击启动时，会打开本文件夹中已经启动的服务。
关闭后再次启动，业务数据会保留在 data 文件夹。
移动文件夹或备份前，请先停止系统；备份时保留整个 data 文件夹。
每个人在自己的电脑上启动后使用自己的数据，各电脑之间不会自动同步。

四、包含的内容
采购、销售、审批、库存、报表、基础资料、系统协同、操作记录。
本包默认使用内嵌 H2 数据库，可离线运行。
金蝶、WMS、MOM 采用本地模拟接口完成流程，不需要企业账号，也未连接金蝶官方企业账套。
数据库优化脚本-mysql.sql 为可选技术资料，需要 MySQL 时才使用。
src 和 pom.xml 为项目源码；target 中为已经编译好的应用。
runtime 为随包提供的 Java 运行环境，许可证保存在 runtime/legal。

五、打不开时
不要直接在压缩包内部启动，先完整解压。
不要单独转发“启动系统.cmd”，需要发送整个压缩包。
启动失败可查看 logs/server.log 和 logs/server-error.log。
学校电脑如限制运行脚本或程序，需要按该电脑的管理规定处理。
