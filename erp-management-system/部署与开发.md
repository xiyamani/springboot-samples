# 部署与开发

## Windows

Windows 64 位免安装包内置 `runtime`，无需另装 Java 或 Maven。完整解压后双击 `启动系统.cmd`，双击 `停止系统.cmd` 停止。包内 `start.ps1` / `stop.ps1` 负责启动和停止，数据位于解压目录的 `data` 文件夹；占用默认端口时自动尝试其他本地端口。详细操作见免安装包中的 `先看这里.txt`。

以下为源码工程的构建与启动方式：

日常双击 `启动系统.cmd`。已包含可执行 JAR 时只需要 Java 21；源码构建需要 Maven 3.9。脚本先尝试当前机器已有工具位置，找不到时使用 PATH 中的 java/mvn。

```powershell
mvn test
mvn package
.\启动系统.ps1
```

构建前先停止正在运行的本项目，避免 Windows 锁定 JAR。端口占用可执行 `.\启动系统.ps1 -Port 8088`。停止脚本只结束 PID 和 JAR 路径均匹配的本项目 Java 进程。

## Linux

在解压后的项目目录使用 Java 21：

```sh
java -Dfile.encoding=UTF-8 -jar target/erp-training-1.0.0.jar
```

默认仅监听 127.0.0.1，数据库相对于当前工作目录保存。容器参考：

```sh
docker compose up --build -d
docker compose logs -f
docker compose down
```

Compose 运行一个容器，通过命名卷保存数据库，宿主机端口只绑定本机。已有 JAR 后不需要容器内 Maven。Dockerfile 的 Java 基础镜像需要联网拉取。本次实测为 Windows Java 运行方式，未执行 Docker 或 Linux 验收。

## 可选 MySQL

默认采用 H2，开启 MySQL 语法兼容模式不代表正在运行 MySQL。现有 `application-mysql.properties` 与 `schema-mysql.sql` 提供切换参考：

```powershell
$env:ERP_DB_URL='jdbc:mysql://127.0.0.1:3306/erp_training?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai'
$env:ERP_DB_USER='erp_user'
$env:ERP_DB_PASSWORD='实际密码'
java -jar target/erp-training-1.0.0.jar --spring.profiles.active=mysql
```

请使用单独的新建课程数据库；初次启动会建表并写入课程数据。此路径未连接真实 MySQL 验证，切换前需核对数据库版本、约束和函数差异。H2 Java 数据库函数仅在 H2 环境注册，其他数据库需单独实现对应过程或函数。

## 金蝶适配器切换

课程默认使用 MOCK：

```powershell
$env:ERP_KINGDEE_MODE='MOCK'
java -jar target/erp-training-1.0.0.jar
```

真实环境需要在测试账套中提供：

```powershell
$env:ERP_KINGDEE_MODE='REAL'
$env:ERP_KINGDEE_BASE_URL='https://实际服务地址'
$env:ERP_KINGDEE_APP_ID='实际应用ID'
$env:ERP_KINGDEE_APP_SECRET='实际应用密钥'
$env:ERP_KINGDEE_ACCT_ID='实际账套ID'
$env:ERP_KINGDEE_USERNAME='实际账号'
$env:ERP_KINGDEE_PASSWORD='实际密码'
$env:ERP_KINGDEE_LCID='2052'
```

REAL 模式只是完成适配器的 HTTP 边界和请求封装，未在本机连接企业金蝶服务。不要把真实密码写入源码、Postman 集合或提交到 Git。

## 项目结构

```text
src/main/java/cn/training/erp
  ApiController / TrainingController     业务接口
  ErpService / WorkflowService           事务与审批
  ErpMapper / TrainingMapper             MyBatis 数据访问
  IntegrationService / Scheduler        适配、队列、重试
  LocalPlatformController / Service      本地平台测试契约
  SecurityConfig                        登录与角色
  SqlLabController / SqlFunctions        数据库优化技术接口
src/main/resources/static               Vue 页面与本地依赖
src/main/resources/*sql                 业务与协同表
src/test/java                           自动化测试
```

可以用 IDEA/Eclipse 打开 Maven 项目，或用 VS Code 编辑前端；工具选型不影响单入口运行。课程版本未使用 Element UI、SVN 或企业 BOS 设计器，不把未使用工具列入成果。

## Git 使用参考

需要展示版本管理时，可在项目目录自行建立本地仓库：

```sh
git init
git add .
git commit -m "ERP course project"
```

项目 `.gitignore` 排除运行数据、日志和构建结果。未替用户创建远程仓库或发布代码。压缩交付包包含源码与已构建 JAR。
