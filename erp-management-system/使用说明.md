# ERP 管理系统使用说明

## 启动

双击 `启动系统.cmd`，浏览器打开 `http://127.0.0.1:8087`。这是一个入口、一个 Java 服务，业务界面和接口联调服务随同启动，无需公司账号。

Windows 免安装包内置 Java，先完整解压即可使用；如果默认端口被占用，免安装包会自动选择其他空闲端口并打开实际地址。首次使用请先看 `先看这里.txt`。

| 角色 | 账号 | 初始密码 | 操作范围 |
| --- | --- | --- | --- |
| 管理员 | admin | admin123 | 全部业务与联调操作 |
| 业务员 | buyer | buyer123 | 资料维护、建单、提交、作废 |
| 审批主管 | reviewer | review123 | 查看、通过、驳回 |
| 仓库员 | keeper | keeper123 | 审批后入库、出库 |

这是本机课程环境的固定账号，界面可选择角色并带入账号。关闭浏览器不停止服务；免安装包双击 `停止系统.cmd`，源码工程执行 `停止系统.ps1` 停止本项目。切换账号使用左下角退出按钮。

登录后首页会显示对应岗位工作台，左侧导航也按角色收缩：业务员看到采购销售与基础资料，审批主管进入审批中心，仓库员进入库存执行，管理员可以看到全部模块。直接输入其他页面地址时，系统会自动回到该角色允许的首页。

## 完整业务操作

1. 基础资料：新增商品、供应商、客户。新增商品初始库存为零，商品编码和单位建立后固定。
2. 采购管理：新建采购单，选择供应商、商品、数量、单价，保存草稿。
3. 单据详情：点击“提交审批”。主管在“审批中心”通过或填写原因驳回；驳回后可以重新提交。
4. 审批通过后，仓库员在单据详情确认入库。库存、成本、流水和接口任务一起保存。
5. 销售管理：同样经过建单、提交、审批、确认出库。库存不足会阻止整单出库。
6. 库存管理：核对结存与出入库流水，导出 CSV。
7. 经营报表：按日期查看已完成销售的收入、成本、毛利和分类/客户分布，导出报表。

管理员可在一个账号下完成全流程；需要展示岗位分工时再切换角色。

## 系统协同

- ERP 数据通道：“同步物料”导入两项测试物料，重复同步不覆盖已有库存和成本。
- ERP 通道页面会显示“金蝶云星辰业务账套”、采购/销售/库存业务记录数；当前为本地 `MOCK` 适配，数据按金蝶常用单据字段组织。
- 单据同步：入库/出库后生成 ERP 与 WMS 任务。每 15 秒自动处理待发送任务，也可点击“发送待处理任务”。
- 查看报文：检查业务请求 JSON、平台回执、发送次数与每次结果。
- 失败重试：在“联调场景”设置下一次 WMS 请求失败，然后发送任务。失败任务保留，点击“重试”恢复；成功任务不会重复投递。
- 生产工单：查看 MOM 工单，填写完成数量并报工；在“其他报文”查看真实 XML 请求和响应。

联调接口在同一 Java 服务内部通过 HTTP 调用，不需要另开辅助程序。截图中的网页账套用于查看产品界面和业务样例；它没有绑定企业，不能直接作为外部 API 凭证。本系统因此用同字段结构的本地适配器完成课程联调，未冒充已经连接金蝶企业账套。

金蝶适配器的切换开关是 `erp.kingdee.mode`，默认 `MOCK`。课程环境保持 MOCK；生产环境准备好企业地址和授权后，可切换为 `REAL` 并配置 `ERP_KINGDEE_BASE_URL`、`ERP_KINGDEE_APP_ID`、`ERP_KINGDEE_APP_SECRET`、`ERP_KINGDEE_ACCT_ID`、`ERP_KINGDEE_USERNAME`、`ERP_KINGDEE_PASSWORD`、`ERP_KINGDEE_LCID`。

## 数据库优化

SQL 优化内容已从业务页面移到 MySQL 数据库，脚本位于 `数据库优化脚本-mysql.sql`。使用 Navicat 执行后，会在 `erp_training.sql_lab_orders` 中建立 20,000 条独立实验记录和 `idx_lab_partner_date` 联合索引。

脚本同时提供优化前后的 `EXPLAIN` 查询：优化前对索引列做类型转换，优化后直接使用 `partner_id` 条件。两条查询结果应保持一致，执行计划中优化后应使用 `idx_lab_partner_date`。

## 数据与备份

默认数据保存在 `data/erp.mv.db`，日志位于 `logs`。原机升级前的数据副本保存在 `data-backups`，原有商品、订单和库存不清空。发给其他人的免安装包不包含原机数据库和备份，首次启动建立独立的课程业务数据。

备份时先停止服务，再复制整个 `data` 文件夹。恢复时同样先停机，并保留恢复前备份。不要把不同日期数据库文件混合覆盖。

初始业务数据含 8 个商品、4 个往来单位、10 张单据；另有 2 张生产工单。数据库优化样例单独保存在 MySQL 的 `erp_training` 数据库中。同步物料和课程操作会继续增加记录。

## 开发环境与边界

Java 21、Spring Boot 3.5.7、Spring MVC、MyBatis 3.0.4、Spring Security、Vue 3.5.22、JavaScript、HTML/CSS、Lucide 图标、本地 H2 文件数据库。前端库随项目保存，无需 CDN。

本版面向桌面浏览器，范围为单组织、单仓、人民币账套；没有企业生产接入、BOS 插件、财务凭证、税务、退货红冲、批次、多仓或移动端。

源码构建、MySQL 可选配置和 Docker/Linux 参考方式见 `部署与开发.md`。课堂操作顺序见 `课堂操作步骤.md`。
