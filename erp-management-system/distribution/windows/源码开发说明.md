# Java 源码开发说明

这是同一个 ERP 系统的完整 Maven 工程，运行包内同时提供源码。

## 技术与目录

- 后端：Java 21、Spring Boot、Spring MVC、Spring Security、MyBatis。
- 前端：Vue、JavaScript、HTML、CSS，位于 `src/main/resources/static`。
- 数据库：默认使用本地 H2 文件数据库，另附 MySQL 配置和优化脚本。
- 后端源码：`src/main/java/cn/training/erp`，共 20 个 Java 文件。
- 自动化测试：`src/test/java/cn/training/erp`，共 2 个 Java 测试类。
- Maven 配置：`pom.xml`。

## 用 IDEA 打开

1. 先完整解压压缩包。
2. 在 IDEA 中打开包含 `pom.xml` 的项目文件夹，作为 Maven 项目导入。
3. 将 Project SDK 设置为 JDK 21，等待 Maven 下载依赖。
4. 运行 `cn.training.erp.ErpApplication`，工作目录设为项目根目录。
5. 浏览器访问 `http://127.0.0.1:8087/`。如果端口正在使用，先停止其他系统副本。

使用其他编辑器时，在项目根目录执行：

```powershell
mvn test
mvn package
java -Dfile.encoding=UTF-8 -jar target/erp-training-1.0.0.jar
```

开发编译需要 JDK 21 和 Maven 3.9 或更新版本；首次下载依赖需要网络。
免安装包内的 `runtime` 用于直接运行系统，不是用于源码开发的完整 JDK。
重新打包前先停止正在运行的同目录服务，以免 Windows 锁定 JAR。

数据库会相对工作目录保存在 `data/erp.mv.db`。源码包不附带原作者的数据库、备份或日志，首次运行自动创建课程业务数据。
金蝶、WMS、MOM 的默认响应来自本地模拟接口，未连接官方企业账套。
