# 接口说明

基地址：`http://127.0.0.1:8087`。本说明对应项目自己的接口契约，不是金蝶官方文档。

## 登录与权限

先 GET `/api/auth/session`，保留 Cookie 并取得 `csrfToken`。POST `/api/auth/login` 使用表单 `username`、`password`，带上 `X-XSRF-TOKEN`。登录成功后再次获取 session，刷新令牌。后续业务写请求使用同一会话 Cookie 与最新令牌。

退出使用 POST `/api/auth/logout`。无登录返回 401，无权限或缺少 CSRF 返回 403，业务校验失败返回 400。界面已自动处理这些步骤。

## 业务 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/health | 服务版本和就绪状态 |
| GET | /api/workspace | 商品、伙伴、订单、流水、审批、任务与审计 |
| POST | /api/products | 新增商品，业务员/管理员 |
| PUT | /api/products/{id} | 编辑商品 |
| POST | /api/partners | 新增往来单位 |
| POST | /api/orders | 建立草稿 |
| GET | /api/orders/{id} | 明细与审批 |
| POST | /api/orders/{id}/submit | 业务员提交 |
| POST | /api/orders/{id}/approve | 主管通过，JSON `{"note":"同意"}` |
| POST | /api/orders/{id}/reject | 主管驳回，note 必填 |
| POST | /api/orders/{id}/post | 仓库执行，必须已通过审批 |
| POST | /api/orders/{id}/cancel | 作废未完成且非待审批单据 |
| GET | /api/export/inventory | 库存 CSV |
| GET | /api/export/movements | 流水 CSV |

建单示例，其中 ID 必须取本账套真实资料：

```json
{
  "type":"PURCHASE",
  "partnerId":1,
  "businessDate":"2026-10-15",
  "note":"原材料补货",
  "lines":[{"productId":1,"quantity":5,"unitPrice":10}]
}
```


## 本地平台测试端点

所有 `/training-api/**` 请求要求 `X-Training-Token: training-local-token`，不使用浏览器登录。可通过 `ERP_INTEGRATION_TOKEN` 统一改变测试令牌。

| 方法 | 路径 | 数据 |
| --- | --- | --- |
| GET | /training-api/health | JSON 健康状态 |
| GET | /training-api/kingdee/materials | JSON 物料目录 |
| POST | /training-api/kingdee/documents | JSON 业务单据 |
| POST | /training-api/wms/documents | JSON 入库/出库单 |
| GET | /training-api/kingdee/documents | 已接收单据 |
| GET | /training-api/wms/documents | 已接收单据 |
| POST | /training-api/mom | SOAP 1.1 风格 XML |

单据发送要求 `Idempotency-Key`，ERP 键形如 `KINGDEE-11-SAVE_DOCUMENT`，WMS 键形如 `WMS-11-RECEIPT` 或 `WMS-11-ISSUE`。响应包含 success、receiptNo、duplicate。故障场景返回 HTTP 503；调用方保存失败记录后可以继续重试。

SOAP Content-Type 为 `text/xml`，命名空间为 `urn:training:mom`：

```xml
<soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/" xmlns:m="urn:training:mom">
  <soap:Body><m:ReportWork><m:Record>
    <m:orderNo>MO-2026-001</m:orderNo>
    <m:quantity>2</m:quantity>
    <m:requestId>demo-report-001</m:requestId>
  </m:Record></m:ReportWork></soap:Body>
</soap:Envelope>
```

工单查询使用 `<m:GetWorkOrders/>`。XML 解析禁止 DOCTYPE 和外部实体。当前 SOAP 未发布 WSDL，异常使用 HTTP 状态及 JSON 错误信息，属于课程范围的受限契约。

Postman 集合见 `ERP接口集合.postman_collection.json`。按编号执行，集合脚本自动保存令牌、Cookie、订单与任务 ID；不需要手填公司信息。

## 金蝶适配器

`KingdeeApiClient` 保留了登录、查询单据和保存单据三个边界方法。MOCK 模式不访问网络，显示为“金蝶云星辰业务账套”，返回带 `FID`、`FBillNo`、`FDate`、`FMaterialNumber`、`FMaterialName`、`FQty`、`FPrice` 的业务数据；REAL 模式使用配置的地址发送 JSON 请求，并把账号、应用密钥和账套参数放入登录请求。

适配器把金蝶字段转换为系统内部的 `billNo`、`date`、`materialNumber`、`materialName`、`quantity`、`amount`，所以后续库存、报表和审计代码不依赖外部字段命名。`/api/integrations/kingdee/demo` 便于课堂直接检查模式、请求字段和仿真结果。
