# 课堂操作步骤

建议 8 至 10 分钟，使用同一应用完成。项目介绍可表述为：“本 ERP 管理系统是一套制造业务课程项目，围绕采购、销售、库存、审批和系统协同实现完整业务闭环，接口通过本地测试环境验证。”

## 1. 业务概览（1 分钟）

登录管理员，介绍本月采购销售、库存资产、库存预警和最近单据。点开一张已完成单据，说明只有过账才影响库存。

## 2. 采购审批与入库（2 分钟）

新建采购单，选择供应商和 MAT-001，数量 5。保存后打开详情，依次提交、审批通过、确认入库。查看库存流水并核对增加 5。

需要强调岗位分工时，用 buyer 建单提交、reviewer 审批、keeper 入库；每次从左下角退出再登录。管理员可完成完整流程。

## 3. 销售与校验（1 分钟）

用现有库存商品创建销售单并完成审批出库，核对库存扣减和报表收入。可选：创建超过库存的销售单，审批后尝试出库，展示阻止整单出库；该单保留待处理即可。

## 4. 系统协同（2 分钟）

进入系统协同，同步物料；第二次同步不会重复新增。

查看过账产生的 ERP/WMS 任务，点击发送。打开报文，展示请求、回执编号和发送次数。任务若已自动处理，无需重复点击。

要查看异常处理：先设置 WMS“下一次请求失败”，再完成一张新的采购单并发送待处理任务。失败任务点击“重试”后成功，记录中保留两次结果。定时调度可能先执行任务，因此以任务实际状态为准。

点击 ERP 数据通道下方的适配信息，说明当前显示为“金蝶云星辰业务账套”；查看采购、销售、库存三组业务记录，以及字段由适配器转换后再进入业务服务。说明截图中的网页账套没有企业 API 凭证，本项目用本地标准报文完成同样的对接流程。

## 5. 生产协同（1 分钟）

切换生产工单，选择未完成工单报工 1。核对已完成数量增加，再打开其他报文中的 MOM 记录，查看 SOAP XML 请求与响应。

## 6. 数据库优化与追溯（1 分钟）

打开 Navicat 连接本机 MySQL，进入 `erp_training` 数据库，打开项目中的 `数据库优化脚本-mysql.sql`。执行两组 `EXPLAIN`，说明转换索引列与直接比较的差异，展示优化后使用 `idx_lab_partner_date`，再核对两组查询结果一致。

最后打开操作记录，检索刚才的单据编号，展示提交、审批和执行的责任人。

## 常见问答

**为什么不使用公司账号？** 本项目使用独立课程账套和本地接口测试环境，业务和接口机制可以完整验收，无需访问企业生产资料。

**是不是直接对接金蝶？** 目前实现的是 ERP 数据通道的本地教学契约，实际请求、回执、重试和幂等可检查；未申请或连接金蝶官方企业环境。

**哪些是真实运行的？** 页面、登录授权、数据库持久化、审批、库存事务、报表、HTTP、XML、失败重试与 SQL 执行均真实运行。企业基础资料和外部平台响应使用测试数据。

**可以扩展什么？** 根据实际产品接口增加认证与字段映射，再补充真实环境验证；也可扩展退货、多仓、批次和财务模块。当前不把这些列为已经完成。
